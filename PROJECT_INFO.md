## 🎯 About the Project

Linear actuator control system applying tensegrity (tensile integrity) principles. The project demonstrates creating stable structures through force balance in software code.

## 🛠️ Applied Technologies

### Hardware
- **Arduino** - microcontroller
- **H-bridge drivers** - motor control
- **Linear actuators** - actuating mechanisms
- **Potentiometers** - feedback

### Software
- **C++** - main language
- **PID algorithm** - feedback control
- **OOP** - modular architecture
- **Tensegrity principles** - stable structures

## 📊 Results

- **Accuracy**: ±0.1 mm
- **Frequency**: ~100 Hz
- **Response**: <10 ms
- **Stability**: High

## 🎓 Tensegrity Experience

This project became an excellent experience applying tensegrity principles in programming:

1. **Structural integrity** - each component supports overall stability
2. **Force balance** - balanced interaction between modules
3. **Adaptability** - system easily adapts to changes
4. **Efficiency** - optimal resource usage
